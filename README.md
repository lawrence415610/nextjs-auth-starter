# Local Pulse(本地脉搏) MVP

## Tagline:
Reddit on a map, powered by AI.
基于地图的本地生活论坛，用户通过 AI 在 30 秒内了解一个陌生地理区域。一个地图驱动的本地论坛，用户可以在地图上查看本地讨论、近期变化、氛围摘要和基于数据的 AI 推荐。

## Core promise:
用户通过 AI 在 30 秒内了解一个陌生地理区域。

## Core Interface
- Full screen map
- Floating AI chat box
- Area pulse panel
- Map pins for local threads

## Core User Flow
1. User opens map
2. User drags map to an area
3. System fetches posts and location nodes within current bounds
4. Area Pulse panel shows summary
5. User asks AI what to know around here
6. AI replies and highlights relevant pins on map

## MVP Scope
- Sydney CBD / Haymarket / Newtown seed data
- Anonymous posting
- AI summary based on local posts
- No payment
- No business dashboard
- No private messaging
