# Local Pulse(本地脉搏) MVP

## Tagline:
Local Pulse v0.1：AI-powered map directory for local small businesses.
一个给本地小商家使用的 AI 地图黄页。商家可以自己发布资料和公告，普通用户可以在地图上查看附近信息，AI 帮用户快速理解一个区域。

## Core Interface
1. 地图首页
2. 商家注册/登录
3. 商家创建 listing
4. 平台审核 listing
5. 地图显示 approved businesses
6. 商家发布公告/update
7. AI 根据当前地图范围总结区域
8. 普通用户无需登录即可浏览

## Core User Flow
1. User opens map
2. User drags map to an area
3. System fetches posts and location nodes within current bounds
4. Area Pulse panel shows summary
5. User asks AI what to know around here
6. AI replies and highlights relevant pins on map
